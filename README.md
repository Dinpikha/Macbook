# MacBook Pro Showcase

A React and Three.js product showcase for MacBook Pro with interactive 3D models, scroll animations, and responsive sections.

## Features

- Interactive 3D MacBook Pro viewer built with React Three Fiber and Drei.
- 14-inch and 16-inch model switching with animated transitions.
- Color switching between light and dark finishes.
- User-controlled 3D model interaction through presentation controls.
- Scroll-driven GSAP animations for the showcase, performance, features, and highlights sections.
- Pinned feature section with a rotating 3D MacBook model and synced feature content.
- Video and image-based product sections, including hero, showcase, feature, and performance media.
- Responsive layout and model scaling for desktop and smaller screens.
- Shared viewer state for selected color, size, and feature texture using Zustand.

## Tech Stack

- React
- Vite
- Three.js
- React Three Fiber
- Drei
- GSAP
- Zustand
- Tailwind CSS
- react-responsive
- oxlint

## Run locally

```bash
npm install
npm run dev
```

Build and preview the production version:

```bash
npm run build
npm run preview
```

Run linting:

```bash
npm run lint
```
